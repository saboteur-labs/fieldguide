# The controls

| Name on the machine | Where it is | What it does |
| --- | --- | --- |
| **MAIN** | Back | Switches the power on (**I**) and off (**O**). |
| **Diractance** | Front, the large dial | Sets how much power the machine puts out: **Low**, **Nominal** or **High**. |
| **Prefabulate** | Front, below the dial | Starts the machine after you switch it on. |
| **Marzlevane** | Front, above the dial | A light that shows what the machine is doing. |
| **Waneshaft Lock** | Right side | A lever with two positions: **Locked** and **Free**. |
| Display | Next to the light | Shows an error code when something is wrong. Blank otherwise. |
| **Spurving bearing oil window** | Left side | Shows how much oil is left. |
| **Panametric fan outlet** | Back | Where the exhaust hose attaches. |

## What the Marzlevane light means

- **Steady green**: ready.
- **Blinking amber**: warming up. Wait.
- **Steady red**: something is wrong. Check the display for a code, then see
  [Error codes](../care-and-troubleshooting/error-codes.md).

## Which Diractance setting to use

Use **Nominal** every day. Use **High** only if the manual for the machine you are
powering asks for it. **Low** is for starting and stopping.
