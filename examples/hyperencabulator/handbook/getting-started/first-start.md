# Your first start

Before you begin, make sure you have finished [Setting up](setting-up.md): the oil is
at the line, the exhaust hose is connected, and **Waneshaft Lock** is at **Locked**.

1. Turn the large **Diractance** dial on the front to **Low**.
2. Plug in the power cable and switch **MAIN**, on the back, to **I**.
3. Press the round **Prefabulate** button once.
4. Watch the **Marzlevane** lamp above the dial. It blinks amber while the machine
   warms up, which takes about 90 seconds.
5. When the lamp turns steady green, turn the dial to **Nominal**.

The HX-1 is now running and ready to use. [Starting and stopping](../everyday-use/starting-and-stopping.md)
covers what to do each day.

If the lamp turns red, or a code like **E3** appears on the small display, see
[Error codes](../care-and-troubleshooting/error-codes.md).
