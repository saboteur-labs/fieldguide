# HyperEncabulator Handbook

The Saboteur HyperEncabulator HX-1 keeps the power to your other workshop machines
steady and balanced, so machines that are sensitive to changes in their power supply
keep working properly.

The machine's parts have unusual names, like the **Marzlevane** lamp or the
**Diractance** dial. This handbook uses those names exactly as they are printed on the
machine, so you can find them, and says in plain words what each one does.

New to the HX-1? Start with [Setting up](getting-started/setting-up.md).
